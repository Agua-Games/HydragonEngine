# Node Graph Examples

This directory contains various examples of how to use the Node Graph system in different scenarios. Each example is a self-contained C++ file that demonstrates a specific use case.

The syntax uses fluent C++ coding style and C++17 features, such as `auto` and `std::make_shared`.
We aim for less verbose, more readable code, and that the node graph implementations in code be the basis for setting up:

- Gameplay systems.
- Physics systems.
- Asset processing pipelines.
- AI systems.
- Procedural systems and evolution.
- Audio systems.
- Post-processing chains.
- Rendering systems.
- Scene graph setup, customization, usd variants, instancing, layering setup, etc.
- AI behavior trees.
- Systems integration.
- Systems harmony maintenance, orchestration, coordination, evolution.
- Many more.

The syntax may vary between example files, because we'll be constantly updating them until they're not pseudo-code anymore.
